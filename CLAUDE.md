## Stack et commandes

Site vitrine **single page** de Happy Culteur (en français) en **HTML/CSS/JS purs**, sans build, sans dépendance npm. Animations **GSAP** 3.13 (CDN cdnjs : Observer, ScrollTrigger, SplitText, DrawSVGPlugin) réintroduites section par section, en repartant de zéro : pour l'instant seul le tracé du soulignement du hero (`.underline`) est animé. **Navigation par panneaux** pour Accueil et Qui sommes-nous (`.slides`, GSAP Observer, `js/main.js`) ; à partir de « Pourquoi collaborer » (`#collaborer`, hors `.slides`) la page défile librement avec **Lenis** (inertie), le slider se verrouille/déverrouille (`is-locked`/`is-free`) ; les sections libres sont dans `.free-zone` ; `#services` y est une **rangée de 4 colonnes tenant dans un écran** (`.svc__item` : illustration SVG inline animée par GSAP — arrivée orchestrée, boucle de vie par illustration, survol — + titre, tags, texte ; 1er paragraphe visible, suite dans `<details>` ) ; : chaque `<section class="panel">` est un écran plein ; molette, swipe tactile, clavier et liens `#id` changent de panneau avec une transition. Actif seulement si `(min-width: 62rem) and (min-height: 46rem)` (classe `is-slider` sur `<html>`, posée dans le `<head>` puis gérée par `gsap.matchMedia`) ; sinon page à défilement natif. Le passage vers les sections libres redéfinit le panneau courant sur le dernier (« Qui sommes-nous ») : en remontant on repasse par lui avant l'accueil ; l'`Observer` est scindé en `wheel` + `touch` (le mode touch avale les clics, il ignore `a, button, summary`) ; en quittant « Qui sommes-nous » à la molette/au swipe, simple élan d'un tiers d'écran puis défilement libre (pas d'alignement forcé sur `#collaborer`, refusé par le client) ; un lien vers une section passe par `travel()` (`main.js`) : court trajet (≤ 1 écran) = glissé dont la durée suit la distance, long trajet = voile blanc `.veil` (0,3 s), saut exact sur la cible puis le voile s'efface (pas de glissé final : il laissait voir le bas de la section précédente, refusé ; on ne traverse plus en accéléré la galerie épinglée) ; pendant un trajet la navbar reste affichée et le lien actif est posé d'emblée (`traveling`) ; depuis la page libre, un lien vers un panneau remonte en haut puis change de panneau (de loin : saut et panneau affiché sous le voile, sans transition, `goTo(i, instant)`) (`unlocking` bloque le reverrouillage pendant le trajet, sinon Lenis s'arrête avant `onComplete`) ; `html.lenis { scroll-behavior: auto }` obligatoire (sinon le `scroll-behavior: smooth` natif anime les sauts « immédiats » de Lenis) ; `history.scrollRestoration='manual'` et un lien `#services` au rechargement déverrouille directement. « Qui sommes-nous » porte une photo d'équipe (`collaboration.jpg`, motif feuille, **provisoire**, différente de celle du hero). Les « Lire la suite » de `#services` ouvrent une feuille (vague d'encre `clip-path`). Pour ajouter une section : `<section class="panel" id="…" data-label="…">` dans `<main>`, éléments à animer à l'arrivée avec `data-slide-in` (ne pas le mettre sur un élément déjà animé par GSAP, ex. le bouton du hero). Lien actif et hash se gèrent seuls. Le contenu d'un panneau doit tenir dans 100svh en mode slider. Ajouter ScrollTrigger seulement quand une animation au scroll sera nécessaire.

- Lancer en local : `python3 -m http.server 8000` puis http://localhost:8000 (ou ouvrir `index.html`).
- Pas de lint ni de tests configurés.

Fichiers : `index.html` (une seule page ; **hero (`#accueil`) et « Qui sommes-nous ? » (`#qui-sommes-nous`) construits**, `#equipe`, `#histoire` et `#contact` construits aussi), `css/style.css` (tokens `:root` en tête, sommaire numéroté), `js/main.js`, portraits **provisoires** de « Notre équipe » `assets/img/equipe/{prénom}-{id Unsplash}.jpg` (licence Unsplash, portraits 4:5 recadrés sur le visage, jeunes en tenue sombre au bureau ; Fotografía Editorial, Francis Ledger, Rodrigo Rodrigues, Shane Ryan Herilalaina, Collins Lesulie, The Dream Archives ; à remplacer par les vraies photos de l'équipe), photos de groupe **provisoires** de « Notre histoire » `assets/img/histoire/{chapitre}-{id Unsplash}.jpg` (licence Unsplash, 4:3 1200×900 ; Ufoma Ojo (noir et blanc, les débuts), Vitaly Gariev ×2, Michael Ali ; à remplacer par les vraies photos de groupe de l'équipe), photos non utilisées pour l'instant (Unsplash, licence Unsplash ; anciens heros) : `assets/img/sourire-poste.jpg` (Vitaly Gariev, UHfJI_lZoPo), `assets/img/equipe-ecran.jpg` (Creatopy, oMtJYEbniH8), `assets/img/relation-client.jpg` (baljkann4, wnpf3Q5pkXA), `assets/img/equipe.jpg` (Jud Mackrill).

Conventions à respecter :
- SEO/accessibilité : un seul `<h1>`, chaque `<section>` porte `aria-labelledby` vers son titre, métadonnées + JSON-LD dans `<head>`, lien d'évitement, `aria-expanded` sur le menu mobile.
- Animations : quand GSAP sera réintroduit, l'état masqué initial doit être défini en CSS sous `.js` **et** `prefers-reduced-motion: no-preference` (sinon contenu invisible si GSAP ne charge pas), et les animations vont dans `gsap.matchMedia()`. **Départ des animations = l'instant où l'élément entre à l'écran** (`start: 'top bottom'`, demandé par le client : « pas avant, pas après ») ; boucles de vie actives de `top bottom` à `bottom top`.
- Couleurs/polices : uniquement via les variables CSS (`--c-*`, `--f-*`).
- Sections restantes à construire dans l'ordre de la nav ; `canonical`, `og:url`, `og:image` et l'URL du JSON-LD sont à renseigner.

### Couleurs

| Rôle | Valeur estimée | Usage |
|---|---|---|
| Jaune/ambre (accent) | `#F7B731` (≈ `#F5B335`–`#FAB82E`) | Boutons CTA, mots clés du titre, soulignement du lien actif, logo |
| Jaune foncé pour texte (`--c-accent-ink`) | `#B87A06` | Mots en jaune dans un **titre** (« faire grandir ») : le jaune vif n'a que 1,8:1 de contraste sur blanc, celui-ci 3,6:1 ; le jaune vif reste pour les aplats, soulignements, boutons |
| Texte principal | `#14142B` (quasi noir bleuté ; ≈ `#111827`) | Titres, navigation |
| Texte secondaire | `#4B4B5A` | Sous-titre du hero |
| Fond | `#FFFFFF` | Fond de page, nav |
| Texte sur bouton jaune | `#14142B` | Libellé + flèche du bouton |

Principes : fond blanc très aéré, jaune uniquement en accent (CTA, mot mis en valeur, soulignement), noir/bleu nuit pour le texte. Le noir des polos de la photo apporte le contraste, ne pas l'ajouter en grands aplats.

| Logo | Serif manuscrit/fin jaune + sous-titre en petites capitales espacées | À remplacer par le fichier du logo fourni |
